Front-end application that showcases igneous rocks for my geology class.

## Tech Stack 

- Next.js
- React
- Tailwind CSS
- TypeScript

## Getting Started

1. Run `npm install` to install the dependencies.
2. Run `npm run dev` to start the development server.
3. Open [http://localhost:3000](http://localhost:3000) to view the application.

**Note:** Make sure to have packages like 'react-icons' installed (along with'tailwindcss', 'next', 'react', 'react-dom', and 'typescript' but these packages usually come installed with Next.js set up).
